关于输入法的几个文件

五笔设置文件
~/.config/fcitx5/table/wbx.conf

个人码表目录
~/.local/share/fcitx5/table
wbx.history
wbx.user.dict
五笔输入历史
五笔个人码表

码表转文档，因为是个人词库，要加上 -u
```
libime_tabledict -d -u wbx.user.dict wbx.user.txt
```
文档转码表
```
libime_tabledict -u wbx.user.txt wbx.user.dict
```
历史与文档的转换(可能有误)
```
libime_history wbx.history /dev/stdout > wbx-history.txt
libime_history -c wbx-history.txt /dev/stdout > wbx-new.history
```

个人系统主词库
~/.local/share/libime

码表转文档
```
sudo libime_tabledict -d wbx.main.dict wbx.txt
```
文档转码表
```
sudo libime_tabledict wbx.txt wbx.main.dict
```


额外码表，如果你想为某个输入法追加自定义码表，可以创建并使用 
`~/.local/share/fcitx5/table/wbx.dict.d/` 

目录，将 `.txt` 或 `.dict` 文件放入其中即可被加载。

~/.local/share/gnome-shell/extensions/kimpanel@kde.org/
扩展插件目录
panel.js
调整候选框位置
stylesheet.css
调整候选框样式
